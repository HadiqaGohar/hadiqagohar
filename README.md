## 🌟 Featured Projects

### 🏥 [HG-Medicura-AI — AI Medical Assistant](https://hg-medicura-ai.vercel.app/)
Medical domain copilot built for **TiDB AgentX Hackathon 2025**. Agentic AI reasoning (OpenAI Agents SDK + Gemini API) for symptom analysis, triage & specialist recommendations. FastAPI + TiDB Serverless (vector & full-text search) + MongoDB, React + Tailwind frontend with NextAuth.

### 📝 [HG-AI-Resume-Builder — AI Resume Builder](https://hg-ai-resume-builder.vercel.app/)
AI-powered ATS-friendly resume builder built for the **Code with Kiro Hackathon**. Next.js + TypeScript + Tailwind frontend, FastAPI backend with OpenAI Agents SDK, dynamic templates, PDF export via `@react-pdf/renderer`, and Kiro IDE spec-driven workflow.

### 🤖 Operonix AI — Personal AI Employee
Autonomous AI assistant (Digital FTE) for 24/7 task automation. Agent-based, local-first architecture using Claude Code & Obsidian, real-time Python "Watchers" for Gmail/WhatsApp/files, MCP-integrated actions, and a human-in-the-loop approval system.

### ✅ [Doquanta — AI Task Management Platform](https://doquanta.vercel.app/)
AI-powered, cloud-native task management system. Full-stack Next.js & FastAPI, MCP-based AI chatbot, Docker + Kubernetes deployment, real-time reminders & automation.

### 📊 [VigilForge CRM — AI CRM Platform](https://vigilforge.vercel.app/)
Omnichannel CRM integrating WhatsApp, Gmail & web forms. Next.js + FastAPI + Vercel/GCP deployment, automated responses, ticket management, sentiment analysis, and real-time dashboards.

### 📚 [Neurobotics AI Book — Interactive AI Book Platform](https://neurobotics.vercel.app/)
Full-stack AI book app with FastAPI backend & Docusaurus/React frontend. Gemini-powered RAG chatbot, multilingual support, persistent chat history & voice input, Qdrant vector DB + Neon Postgres.

### 🎨 [Figma Design Hackathon — Design-to-Code Implementation](https://figma-design-hackathon.vercel.app/)
Pixel-perfect Next.js + TypeScript + Tailwind implementation of Figma designs, with dynamic comments, routing/middleware, and clean scalable architecture.

### ✍️ HG Blogs — Latest Blogging Website
Next.js blog platform with Tailwind CSS + Sanity CMS, user auth, subscriptions, commenting, and performance-optimized delivery on Vercel.
